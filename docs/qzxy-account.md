# 趣智钱包与使用码

本次实现参考本地 `C:\Users\touchsky\Desktop\a\linyu` 的 `API-qzxy.md`、`QzxyService.kt`、`MainViewModel.kt` 和 `UseCodeSection.kt`。上游为 [yehu-imei/linyu](https://github.com/yehu-imei/linyu)，采用 MIT 协议。

## 功能范围

- 删除胖乖刷积分任务及其首页卡片、运行日志、暂停与停止逻辑；保留手动签到、启动自动签到、积分余额和开水抵扣。
- 趣智钱包与使用码不依赖胖乖登录或热水器绑定，首页洗澡区和设置的趣智分组均有入口。
- 只查询趣智钱包，不查询或展示一卡通余额，也不提供本地估算。

## 接口与状态

| 操作 | 接口 | 处理 |
| --- | --- | --- |
| 钱包余额 | `GET /account/wallet` | 使用 `money` 字段，单位为元；缺失或不可解析时显示未返回余额 |
| 当前使用码 | `GET /account/useCode/new` | 分别显示查询中、未领取、开启、关闭、状态未知和查询失败 |
| 候选使用码 | `POST /account/useCode/new/generate` | 只预览，不覆盖当前码；展示 `remainTimes` 剩余次数 |
| 确定领取 | `POST /account/useCode/new/set` | 提交完整字符串，保留前导零；成功后重新查询当前码 |
| 开关使用码 | `POST /account/useCode/new/status/update` | 提交 `useCodeStatus=1/0`；成功后重新查询确认 |

钱包数字字段 `accountRealMoney` 在本地 linyu 的记录中以厘返回，不能当成元。这里不使用这些数字字段补余额，避免放大 1000 倍。展示金额按两位小数四舍五入。

候选码使用单调时钟计时，生成后 3 分钟内可领取，超时禁用领取。每天一次的领取限制与每天 20 次的生成限制分开处理，平台返回的限制文案直接展示。取消预览保留原码，但已消耗的生成次数不退回。

同类请求进行中禁止重复点击；退出或重新登录会取消账户请求并作废旧响应。领取或开关结果不确定时隐藏旧码，提示重新查询，避免误以为仍可使用。
